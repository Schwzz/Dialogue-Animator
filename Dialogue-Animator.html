Text Effects  wrap words, close with [/]

[wave][/]Floating wave animation
[shake][/]Shaky text
[rainbow][/]Colour-cycling text
[big][/]Larger text
[small][/]Smaller text

Event Tags  fire instantly while typing

[flash]White flash
[screenshake]Shakes the preview
[pause:2]Hold 2 seconds before continuing
[expr:1] – [expr:4]Swap expression slot mid-line

Example

* This is [wave]really[/] important...
[pause:1.5][expr:2][flash]* WATCH OUT!
